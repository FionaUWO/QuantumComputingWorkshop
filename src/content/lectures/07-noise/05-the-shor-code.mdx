Shor's solution is to *concatenate* the two codes. First encode with the phase flip code, $|0\rangle \mapsto |{+}{+}{+}\rangle$ and $|1\rangle \mapsto |{-}{-}{-}\rangle$. Then encode each of the three qubits with the bit flip code, so that $|\pm\rangle \mapsto \tfrac{1}{\sqrt2}\big(|000\rangle \pm |111\rangle\big)$. The result uses nine qubits:

$$
|0_L\rangle = \frac{\big(|000\rangle + |111\rangle\big)^{\otimes 3}}{2\sqrt2}, \qquad
|1_L\rangle = \frac{\big(|000\rangle - |111\rangle\big)^{\otimes 3}}{2\sqrt2} .
$$

**Bit flips.** Each block of three is a bit flip code. The six observables $Z_1 Z_2$, $Z_2 Z_3$, $Z_4 Z_5$, $Z_5 Z_6$, $Z_7 Z_8$, $Z_8 Z_9$ locate a bit flip within its block.

**Phase flips.** A phase flip on any qubit of a block changes the sign in that block, turning $|000\rangle + |111\rangle$ into $|000\rangle - |111\rangle$. To compare the signs of two blocks, measure

$$
X_1 X_2 X_3 X_4 X_5 X_6 \qquad\text{and}\qquad X_4 X_5 X_6 X_7 X_8 X_9 .
$$

These locate the block whose sign flipped, and applying $Z$ to any qubit of that block repairs it. Note that $Z_1$, $Z_2$ and $Z_3$ have the same effect on the code space, so the code does not need to tell them apart. Codes with this property are called *degenerate*; nothing like it exists classically.

**Both.** A $Y$ error on one qubit is a bit flip and a phase flip on that qubit. The two sets of checks detect each part separately and both are corrected.

<Statement>
**Theorem.** The Shor code encodes one qubit into nine and corrects an arbitrary error on any single qubit.
</Statement>

Eight observables are measured on nine qubits, each halving the dimension of the space of allowed states: $2^9 / 2^8 = 2$, one logical qubit. Lecture 8 makes this counting systematic.
