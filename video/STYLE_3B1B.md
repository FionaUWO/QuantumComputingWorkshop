## 1. 故事：每期只讲一个"换一种看法"

三期都不是"讲完某一节内容"，而是各自卖一个视角：

- 第 1 章：向量既是箭头又是一列数，价值在于两种看法之间来回翻译。
- 第 3 章：矩阵的列就是基向量落到的位置。
- Grover：加速来自"可以走对角线"（勾股定理），而不是"并行试所有答案"。

结构上有四个固定动作：

1. **开头先立一个靶子。** Grover 那期第一句就是"科普里常见的说法几乎一定会带来误解"，然后用一道四选一的小测验让观众先押一个答案，再告诉你最多人选的那个是错的。第 3 章开头是"如果只能选一个让其他内容都通起来的主题，就是这个"。都在 30 秒内回答了"我为什么要看"。
2. **尽早说清路线和范围。** "前三分之二讲基础，目标是走到一个真正的量子算法的最短路径"；"物理留到下一期"；"今天只看二维"。
3. **埋线、回收。** 开头的谜题（密钥函数）、π/4 这个常数、"我撒了一个谎"都是先提一句，后面再兑现。结尾回到开头的误解，给出一个词的新总结（Pythagoras）。
4. **结尾指向下一期**，一句话，不复述全篇。系列片里每期结尾都这样。

**给我们的规则：** 每个 section 的 storyboard 第一行先写"这一段要让观众换成哪种看法"，写不出一句话就先别做动画。我们第 1 讲已有的 running puzzle 正好对应动作 1 和 3。

## 2. 逻辑：先具体后一般，先图后式

- **先例子后定义。** 先看 (−1, 2) 这个具体向量落在哪，再换成 (x, y)，最后才是 a b c d 的一般矩阵。Grover 先用 4 个量子比特的 16 维表格，发现"画面上东西太多"，主动缩到 1 个量子比特的二维情形。
- **先几何后数字。** 每个运算先在图上做一遍（首尾相接、拉伸、翻转），再说"数值上这对应……"。公式是图的记录，不是出发点。
- **替观众问"为什么"。** "为什么是这个加法定义而不是别的？""为什么可以假设这个操作存在？"问完立刻答。
- **坦白省略了什么。** "这是正确想法的 90%""有个细节我留到最后""我不会深入每个门"。到片尾真的回来补上（复数振幅）。这让简化显得可信而不是偷懒。
- **承认难。** "这需要一点时间适应""如果你觉得这套前提很怪，不只你一个"。
- **点名停顿。** 关键处直接说"这里值得停下来想一想"。
- **类比要带保质期。** 勾股类比后面紧跟"别太当真"。

**给我们的规则：** 脚本里每出现一个公式，前面必须已经有一个画面把同一件事演过一遍。每个新名词（ket、qubit、Born rule）都是"先用，再命名"：先让观众看到那个东西，再说"这个有个名字，叫……"。

## 3. 配音（脚本写法）

字幕里量出来的数字：

- Grover 期约 7500 词 / 36.9 分钟，约 **200 词/分钟**；第 1 章我估算约 160 词/分钟。说得不慢，靠的是画面同步而不是放慢语速。
- 平均每句约 26 个词，句子偏长、口语化，靠逗号和从句推进，不是短句排比。
- "you/your" 出现 227 次，"I/me/my" 99 次。全程是"我在跟你一个人说话"。
- 36 分钟里只有 14 个问句。提问是稀有的，所以每次提问都有分量。

措辞特点：

- 第一人称带态度："我喜欢这样想""在我看来""你得承认，这很美"。
- 口语动词代替术语：squish、stretch、walk、flip、massage、coerce。术语出现时常被降格："transformation 基本就是 function 的花哨说法"。
- 路标句很多："好，回到……""所以这是高层概览，下面拆开看""总结一下"。
- 偶尔一句轻微的自嘲或玩笑，从不连着用。

**给我们的规则（对应 `script.py`）：**

- 一行一句照旧，但允许长句，一句里用逗号制造呼吸。这和你之前的偏好一致：停顿靠标点和措辞，不用 break 标签。
- `PAUSE_AFTER` 长停顿只放三处：提问之后、关键画面变形完成之后、换章节之前。其余短。
- `TONE` 大部分行用平稳好奇，少数行标"强调/惊喜"，全片不超过五六处。
- 中文脚本对应地多用"你"，少用"我们来学习"。每段至少一句替观众说出的疑问。

## 4. 动画

画面观察：

- **黑底，少量固定颜色，颜色即身份。** 蓝色网格、黄色向量、绿色 î、红色 ĵ；矩阵里对应的列也是同样的绿和红，公式里的数字跟着图上的对象上色。Grover 期里密钥方向始终是黄色，均衡态始终是青色。一种颜色全片只代表一件事。
- **一切变化都是连续变形。** 网格被整体推斜、向量滑过去、公式的一部分飞到新位置变成下一个公式。几乎没有"切到下一张图"。第 3 章用一段弯曲的非线性变形当反例，只为说明"这不是线性的"。
- **保留参照物。** 变形时背后留一层暗淡的原始网格，专门用来对比"从哪来、到哪去"。
- **数字和图是联动的。** 向量转动时，旁边的坐标和概率条实时跟着变（Grover 期的单位圆 + 概率条 + 分量列表三者同步）。
- **不用的东西调暗，不删除。** 高亮框圈住当前这一行，其余降低亮度。
- **文字极少。** 屏幕上只有标题、标签和公式，衬线数学字体；解释都在旁白里。
- **π 小人**只做三件事：代表观众（困惑、恍然）、代表某种视角（物理学生 / CS 学生 / 数学家）、活跃开头结尾。讲核心推导时不出现。
- **偶尔露一下幕后**：第 1 章结尾直接展示生成动画的代码，Grover 期结尾切到真人黑板镜头。都只在收尾处。

**给我们的规则（对应 `scene.py` / `common.py`）：**

- `common.py` 里定一张固定配色表，例如 |0⟩ 方向、|1⟩ 方向、状态向量、概率各占一种颜色，全系列不换。
- 优先用 `Transform` / `ReplacementTransform` / `ValueTracker` 让对象连续变化，少用 `FadeOut` 再 `FadeIn`。
- 凡是有"状态向量"的画面，旁边放联动的概率条。这是 Grover 期最值得直接借的一个组件，和我们第 1 讲的 100 次测量动画是同一类东西。
- 我们不用 π 小人（那是他们的形象），需要"观众视角"时用我们自己的元素或直接用旁白提问。

## 5. 运镜

- **二维内容镜头基本不动。** 画面的运动来自对象，不来自摄像机。
- **只有三维才转镜头**，而且转得很慢，目的是让人看出立体关系。
- **降维是标志性手法：** Grover 期先在三维里显示向量只在一个平面内运动，然后把这个平面"抽出来"放到右边成为二维主图，三维原图缩到左下角当小窗保留。之后全在二维切片上讲。
- **分屏对照：** 经典 vs 量子并排，按"数据类型 / 比特 / 硬件"三层对齐。
- **复杂就拆。** 一个画面装不下时，先全景给印象，再缩到最小例子，而不是把镜头推近。

**给我们的规则：** 默认固定镜头。只在两种情况动：三维对象需要旋转展示；从"全景"过渡到"局部主图"时把旧图缩成角落小窗。Bloch 球那一讲会用到第一种。

## 6. 展示节奏

- 画面和旁白**同一时刻说同一件事**：说到"第一个数"，那个数这时才亮起。不提前把整屏内容摆出来。
- 一个画面只承担一个意思，讲完就变形成下一个。
- 重要画面出现后留一小段不说话的时间让人看。
- 章节之间有标题卡或明显的语气转折。

**给我们的规则：** storyboard 里每个镜头写清"这一句旁白说完时，屏幕上新出现的只有哪一个东西"。超过一个就拆成两句。

## 开工前自查清单

1. 这一段要让观众换成的看法，能用一句话说出来吗？
2. 开头 30 秒内有没有一个问题或一个被纠正的常见说法？
3. 每个公式之前，是否已有画面把它演过？
4. 每种颜色是否只代表一件事，并和上一讲一致？
5. 有没有画面是"切换"而本可以"变形"的？
6. 有没有哪一句旁白说的东西，屏幕上此刻看不到？
7. 省略了什么，有没有当场说明并在后面交代？
8. 结尾是否回到开头的问题，并用一句话指向下一段？
